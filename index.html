AI-Driven Support Automation & Data Extraction | CIT VeriCash — Part-time

Business Challenge: Support workflows were bottlenecked by manual data extraction, while secure programmatic access to internal support metrics was needed without exposing private network infrastructure or vulnerable firewall configurations.

Impact: Developed high-performance Golang executables to automate data extraction directly from Tableau using Personal Access Tokens (PAT), engineered as callable tools for an AI support model and feeding live operational data. Deployed Cloudflare Tunnels (cloudflared) to bypass strict internal network limitations, allowing safe inbound traffic without opening external ports.

Intelligent Jira SLA & Ticket Assignment Automation | CIT VeriCash — Part-time

Business Challenge: Manual Jira ticket handling caused routing delays and SLA breaches; documentation and updates across Jira and SharePoint created friction, while external cloud-to-internal webhook connections were blocked by restrictive routing policies.

Impact: Engineered an n8n workflow to intercept Jira webhooks, evaluate ticket categorization, intelligently assign tickets to available Support/Ops personnel to guarantee SLA compliance, dynamically update statuses, post context-rich comments, and sync records with SharePoint. Used Cloudflare Tunnels (cloudflared) for a secure encrypted tunnel from Jira Cloud directly to internal n8n.

n8nJira IntegrationIncident ManagementSharePoint Integration

AI-Powered Accounting Workflow & ERP Integration | Joosy Frozze

Business Challenge: Daily financial operations across multiple branches required manual receipt processing, manual calculations, Google Sheets accounting-cycle updates, and journal entries in Daftra ERP — making the process time-consuming and error-prone.

Impact: Built an end-to-end n8n pipeline that condensed the process to a single action: upload daily receipt images → AI extracts key financial fields → structured Google Sheets accounting cycle → Daftra ERP API automatically calculates and generates sales and expense journal entries.
